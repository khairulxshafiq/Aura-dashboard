## 🚀 Dual-Node Architecture (Live Status: Operational)

Sistem dashboard dan empayar AI ini dikuasakan oleh **Dual-Node Infrastructure**:

| Node | Engine / Stack | Server Host | Peranan Utama |
|---|---|---|---|
| **AuraOne (Manager & CTO)** | Hermes Agent (Nous Research) | Tencent Cloud VPS (`43.134.124.127`) | Telegram UI Manager, Prompt Caching, User Interaction |
| **Luma (Execution Engine)** | Google Antigravity (AGY) SDK + Gemini 3.7 | Google Cloud SG VM (`34.87.3.27`) | Autonomous Code Editing, Workspace Audit, Web Research |
